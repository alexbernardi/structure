# Builds

- `toolchain.json` - single source of truth for external tools: Godot version + per-platform archive SHA-256,
  export templates (recorded, optional), Blender version and search paths, minimum Python, Docker base image digest.
- **Build manifest** (generated by `structure.py build`): build version, git commit/dirty/branch, Godot version,
  protocol version, world schema range, image name, asset-manifest sha256, integrated systems, timestamp. Stored as
  image label `org.structure.manifest`, as `res://build_manifest.json` inside the image, and in `.runtime/builds/<tag>.json`.
- **Tags**: `structure-server:<version>-<sha7>` for clean commits, plus `-dirty.<UTC stamp>` for uncommitted trees;
  never overwritten. `structure-server:test` is the docker test suite's throwaway tag.

Reproducible build: `python TOOLS/cli/structure.py build` (equivalent raw command: `docker build -f
INFRASTRUCTURE/docker/server.Dockerfile --target runtime -t structure-server:<tag> .` - the Dockerfile defaults match
`toolchain.json`; the CLI adds the manifest and labels). List builds: `structure.py builds`.
