# bone_ik - interface contract (draft, 0.1.0)

Developed in the `bone_ik` laboratory (its workbench). Not a package room yet: no project consumes it. Changing
anything below bumps the version (minor: additions; major: breaks). Overview: `AGENT-WORKSHOP/DOCUMENTATION/BONE-IK-LAB.md`.

## Entry point

`res://systems/bone_ik/vitruvian_rig.gd` (a `Node3D`; `preload` it, no `class_name`, ADR-0002).
`Rig.new(proportions = null)`, add it to the tree; it builds itself in `_ready` (or call `build()`).

| Member | Contract |
|---|---|
| `VERSION` | `"0.1.0"` |
| `build(proportions = null)` | rebuilds skeleton, joint profile, clips; keeps mode, clip and time; emits `rebuilt` |
| `skeleton: Skeleton3D`, `player: AnimationPlayer`, `definition: Dictionary`, `profile` | read-only for callers |
| `clips() -> PackedStringArray`, `play(name, from := 0.0) -> bool` | authored clips retargeted from the pinned sources |
| `set_mode(Mode)`; `Mode.REST / NEUTRAL / ANIMATION / MANUAL` | pose source |
| `set_joint_angles(bone, Vector3 degrees) -> bool`, `reset_manual()` | manual pose (flex, abd, twist; see the joint profile's labels) |
| `get_joint_angles(bone, stage := "final") -> Vector3` | degrees; stage `"animation"`, `"ik"` or `"final"` |
| `stage_globals(stage) -> Array[Transform3D]` | model-space bone transforms; stage `"rest"`, `"animation"`, `"ik"`, `"final"` |
| `pose_state() -> Dictionary` | `{version, mode, clip, time, response_state, limits_enforced, limit_policy, hinge_align, hinge_transfer_deg, violating_joints, worst_violation_deg, worst_violation_bone, joints: {bone: {final_deg, animation_deg, incoming_beyond_hard_deg, soft_load}}, measurements, ik_layer}` |
| `set_limit_policy(LimitPolicy)`; `PROCEDURAL` (default) / `ALWAYS` / `MEASURE` | limit enforcement |
| `set_limits_enforced(bool)`, `set_hinge_align(bool)` | shortcuts |
| `request_ik_target(effector, Transform3D, influence := 1.0, pole := Vector3.ZERO) -> int` | **reserved (phase 2)**: stores, returns `ERR_UNAVAILABLE`. Effectors `left_hand`, `right_hand`, `left_foot`, `right_foot`; target in the rig node's space |
| `clear_ik_target(effector)` | reserved |
| `apply_impact(bone, impulse: Vector3, world_point: Vector3) -> int` | **reserved (phase 3+)**: returns `ERR_UNAVAILABLE` |
| `set_response_state(state) -> int` | `"animated"` -> `OK`; `"partial_ragdoll"`, `"full_ragdoll"`, `"recovering"` reserved |

## Data

- Proportions: `rig/proportions.gd` (`SPEC`, `PRESETS`, `derive()`), metres and ratios of stature.
- Joint profile: `data/joint_limits.json` (schema 1). Right side generated by mirroring.
- Body plan: `data/body_plan.json` (schema 1).

## Conventions

Model space +Z forward, +X the character's left, +Y up, metres; bone names, parents and rest orientations of
`SkeletonProfileHumanoid`; T-pose rest. The rig never moves its own node and keeps the Root bone at the origin:
the caller owns locomotion and root motion.

## Dependencies

Godot 4.7.2 built-ins only. Authored clips are read from `res://systems/movement_core/assets/quaternius/` (pinned
`movement_core` package assets); without them the rig works with no clips.
