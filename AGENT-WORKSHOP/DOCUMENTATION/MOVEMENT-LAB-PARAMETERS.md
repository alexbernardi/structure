# Movement Lab: parameter and MIDI reference

Generated by `utility/movement/flat-plane/tools/make_param_docs.gd` from the code; do not edit by hand. Overview and architecture:
[MOVEMENT-LAB-2.md](MOVEMENT-LAB-2.md). Units: metres, seconds, radians unless a unit column says otherwise (the gait and rig
parameters use degrees and metres because they are easiest to judge on a controller). Defaults of the gait and proportion
parameters are the values saved after the first tuning session (2026-11-07); `first_defaults` in `presets_gait/` keeps the ones before.
