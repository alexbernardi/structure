# Asset inventory template

## `asset.json` fields (one per asset folder `COMMON-ASSETS/<category>/<id>/`)

| Field | Meaning |
|---|---|
| `asset_id`, `type`, `version` | lower_snake_case id; model / texture / material / animation / shader / audio / script / procedural |
| `description` | what it is used for |
| `origin` | generated by which script, or where it came from (URL, author) |
| `license`, `usage_restrictions` | SPDX id or licence text reference; what is not allowed |
| `owner` | who maintains it |
| `editable_source` | original editable files (spec, .blend via LFS, generator script) |
| `runtime` | `format`, `path`, `sha256`, `bytes` of the processed runtime file |
| `generated_with` | tool versions and parameters (filled by the pipeline) |
| `units`, `axes`, `pivot`, `dimensions_m` | metres; +Y up, -Z forward; pivot convention; measured size |
| `dependencies` | other assets it needs (materials, textures, rigs) |
| `consumers` | project folders that receive a deployed copy |
